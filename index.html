CabaiScan

AI image recognition for chili leaf diseases

A web app that looks at a photo of a chili leaf and tells you which disease it most likely has. It is built on the method from my thesis: the app reads the colour and texture of the leaf and compares it with labelled examples using K-Nearest Neighbors, then shows which examples the answer was based on.

Built with JavaScript, HTML5 Canvas, computer vision, machine learning

TanyaIT

AI helpdesk assistant for office IT problems

Staff describe a problem in everyday Indonesian, such as "internet lemot" or "printer ngadat". TanyaIT sorts the ticket into a category and priority, finds the matching fix from a knowledge base of common problems and drafts a reply the IT team can send. When IT corrects a ticket, the assistant learns from it. It grew out of the requests I handle every day at work.

Built with JavaScript, HTML, CSS, machine learning, text classification, browser storage

2026

BackupWatch

Web dashboard that spots failing backups

Upload a backup log and the dashboard charts every run and flags the ones that need attention: failed or missed jobs, backups that suddenly shrink, unusually long runs and patterns that look like ransomware. Each warning explains in plain language what happened and what to check. It is modelled on the TrueNAS SCALE backups I run in production.

Built with JavaScript, HTML, CSS, data visualization, anomaly detection, CSV import
