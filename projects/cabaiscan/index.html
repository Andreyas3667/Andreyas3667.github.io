CabaiScan

Identify chili leaf conditions from a photo. CabaiScan extracts colour features (HSV histograms and colour moments) and texture features (GLCM), then classifies the leaf with K-Nearest Neighbors, the same method as my undergraduate thesis. Everything runs in your browser; no photo leaves your device.

The demo set is synthetic: leaves generated in code to illustrate four conditions. It shows how the pipeline behaves, not field accuracy. For real results, add your own labelled leaf photos to each class.

How accurate is it?

Leave-one-out cross-validation: each training leaf is hidden in turn and classified using all the others. This compares colour, texture and combined features across values of k.

Method

  1. Resize and segment. The photo is cropped to a 128×128 square; bright, unsaturated background pixels are removed so only the leaf is measured.
  2. Colour features (26). Hue histogram (12 bins of 30°), saturation and value histograms (4 bins each), plus mean and standard deviation of H, S and V.
  3. Texture features (6). A grey-level co-occurrence matrix at 16 levels, averaged over 0°, 45°, 90° and 135°: contrast, dissimilarity, homogeneity, energy, entropy and correlation.
  4. K-Nearest Neighbors. Features are z-score normalised, Euclidean distance finds the k closest training leaves, and the majority label wins (ties go to the nearest).
