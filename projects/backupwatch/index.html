BackupWatch

A backup that "succeeded" can still be useless: it may have copied a half-deleted folder or files a ransomware attack had already encrypted. BackupWatch reads backup job logs and flags failed or missed runs, sudden size drops, abnormal runtimes and mass file changes, each with a plain explanation and a next step.

Detection compares each run with the job's previous 14 successful runs using a robust z-score (median and MAD), so a single bad night does not distort the baseline. The sample log simulates 60 days of a small-office TrueNAS SCALE setup with real-world incidents injected.
